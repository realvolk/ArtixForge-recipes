# ArtixForge-recipes

Community recipe repository for ArtixForge's Power User Mode.

## Structure

- `OFFICIAL/Base/` — Standard recipes (included by default)
- `OFFICIAL/Other/` — Non-critical recipes
- `COMMUNITY/Base/` — user submissions pending review
- `COMMUNITY/Other/` — experimental submissions

## Contributing

1. Fork this repo
2. Add your recipe to the appropriate `COMMUNITY/` folder
3. Add an entry to `.LIST`
4. Submit a pull request

Recipes promoted from COMMUNITY to OFFICIAL will have their original author credited in the file header.
